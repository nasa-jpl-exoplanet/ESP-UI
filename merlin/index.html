Frequently Asked Questions

How do I query the data?
Type your question in natural language in the search box above. For example: "Show me all transit observations" or "Find runs for target GJ 436".
What can I search for?
You can search by target name, run type (transit, eclipse, spectrum), task type (data, timing), algorithm names, or specific instrument configurations.
How do I use the chatbot mode?
Click the "Chat" button at the top to switch to chatbot mode. You can ask questions about EXCALIBUR data, request analysis, or get help understanding results. The bot maintains conversation context.
What's the difference between Chat and Query modes?
Query mode returns structured table results for data exploration. Chat mode provides conversational responses, explanations, and can help with more complex questions or analysis tasks.
Can I combine multiple search criteria?
Yes! Try queries like "All JWST transit runs for GJ 436" or "Show eclipse observations using HST". The more specific you are, the better the results.
How many results can I see at once?
Results are paginated at 100 per page. Use the Previous/Next buttons below the table to navigate through larger result sets.
